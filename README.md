# SHOHIN MARKET

SHOHIN MARKET — современный онлайн-магазин продуктов и товаров с доставкой.

## Возможности

- Каталог товаров
- Категории
- Поиск товаров
- Избранное
- Корзина
- Оформление заказа
- Выбор точки доставки на визуальной карте
- Выбор способа оплаты
- История заказов
- Повтор заказа
- Контакты магазина
- Информация о магазине
- Политика использования
- PWA
- Работа в офлайн-режиме
- Локальное сохранение корзины, избранного и заказов

## Технологии

Проект создан на:

- HTML5
- CSS3
- JavaScript ES Modules
- JSON
- Service Worker
- Web App Manifest
- LocalStorage
